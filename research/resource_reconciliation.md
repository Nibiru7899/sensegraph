Future resource timing uses [QueryUnbiasedInterruptTime](https://learn.microsoft.com/en-us/windows/win32/api/realtimeapiset/nf-realtimeapiset-queryunbiasedinterrupttime), whose working-state clock excludes sleep/hibernation. A temporary [SetThreadExecutionState](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate) `ES_CONTINUOUS|ES_SYSTEM_REQUIRED` requirement prevents automatic idle sleep during a session and restores the previous state afterward. No display/away-mode flag or permanent power-setting change. Explicit user sleep/lid actions are respected by Windows. Frozen OCR code is unchanged and wrapped in this temporary requirement. Evaluation sessions inherit corrected **closed** ledgers; they cannot run concurrently or erase a prior attempt.

Tests require corroborating sleep/resume evidence for any clock correction, reject unsupported refunds, preserve raw accounting, and ignore later out-of-session corrections. Native clock/temporary-hold calls were checked on this Windows host without GPU work. A forced-suspend hardware fault-injection campaign is not performed.
