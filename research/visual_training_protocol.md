# SenseGraph-Net visual training v1

New namespace `experiments/visual_training/v1`. Existing architecture and old experiments remain unchanged. Freeze source/config, v3 split hashes and historical file hashes in `prepare`, before GPU work. Full 1,400 train / 300 validation inventory only; protected tests never read. No additional synthetic generation, GAT training, QA or OCR training.

Architecture: exact ResNet18/FPN/fusion/six active detection heads from neural_spec. Required official ImageNet1K_V1 backbone loaded strictly after new-head initialization; SHA256 prefix f37072fd verified, source/full digest stored. No random fallback. Segmentation has no loss and stays frozen. Backbone BN statistics and affine parameters remain frozen as specified.

Training targets follow the architecture contract: aspect-preserving640 letterbox with actual x/y scales and white padding; class-specific stride4 center heatmaps, widths/heights and sigmoid offsets. Tiny positive-area targets retained. Unsupported series unions recorded, invalid boxes counted. Same-class cell collisions are counted; their regression targets masked rather than silently overwritten. A >1% per-class collision fraction blocks full training pending a new target design. Native image target overlays are a prerequisite visual check. Loss: modified focal centers/keypoints; .1 SmoothL1 extents; L1 offsets; valid-region masking. No rectangular segmentation masks.

Decoder accepts only predicted maps and image-derived affine transform: 3x3 local peaks, confidence>=.10, global top128 before typed NMS .5, positive softplus sizes and sigmoid offsets, inverse transform to native pixels. Precision/recall threshold .25. Returned boxes/classes evaluated against supported physical target categories with the historical AP50/AP75 evaluator; AP is interpolated-envelope area, not COCO101-point mAP. Also report one-to-one native-center point/tick matches within5 pixels, localization errors and FP/FN. The new 300-image validation scope differs from the old first30-chart pilot; report a separately aligned first30 subset before direct numerical comparison. Different640/320 resolution, training duration and heads preclude single-component causal claims.

Bounded verification: 600-second reserved GPU session, with actual wall time charged against the lifetime3600-second cap and all existing M1–M4 usage. Start with100 single-chart optimizer steps, followed by300 cycling four train charts; this is a diagnostic, never full training evidence. Seed20261105, AdamW3e-4, clip1, AMP. Require finite loss/gradients, >=50% mean loss reduction and four-chart supported-class macro recall>=.5, exact checkpoint roundtrip, and actual prediction-overlay approval before full curriculum. Record image-only predictions, per-class/AP/keypoint statistics, all losses/gradients, profile batch duration, peaks allocated/reserved. If tiny fitting fails, stop and diagnose; do not label reduced loss as successful perception.

Before full run, estimate the maximum5+30 epoch campaign from measured warmup batches and validation overhead, conservatively estimating fine-tune batches at2x warmup and adding25% overhead. If projection exceeds remaining authorized seconds, record an explicit GPU-budget proposal and stop for user approval. Do not reset or bypass any ledger. Weight acquisition bytes count through the existing downloader. Full campaign must never be silently replaced by the diagnostic.

Full curriculum when all gates/authorization permit: B1, accumulation8, AdamW, decay1e-4, gradient clip1. Five warmup epochs (ResNet frozen). Up to30 further epochs with C4/C5 unfrozen except BN, backbone1e-5 and new layers3e-4. First epoch per stage linear LR warmup, then cosine decay to1% initial LR. Accumulation divides by actual group size including final partial groups. Validation each epoch; earliest best AP50 checkpoint, stop fine-tuning after minimum5 epochs and5 epochs without >=.5% relative or1e-4 absolute improvement. Save optimizer/scaler/RNG, model, histories, per-epoch overlays and memory. Budget exhaustion saves incomplete epoch/checkpoint without claiming convergence. Interrupted reservations remain charged; existing attempts must not be overwritten.

Main commands: `python -m sensegraph.visual_experiment acquire`, `prepare`, `smoke`, `train`, `verify`. Use project-local Python3.11. Full campaign command requires actual visual approval; programmatic gate checks happen before it allocates GPU. Report in `research/perception_training_report.md`; partial or blocked outcomes remain explicit.
